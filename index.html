 Lab 1: Static Analysis

      
# Pull APK
adb shell pm path com.target.app
adb pull /data/app/com.target.app/base.apk

# Decompile
apktool d base.apk -o target_src
jadx -d jadx_out base.apk
apkleaks -f base.apk -o leaks.txt

# Look for exports and secrets
grep -E "exported|debuggable|allowBackup" target_src/AndroidManifest.xml
grep -rn "api_key\|secret\|password\|token" target_src/smali/

    


    

      
 Lab 2: Frida Root & SSL Bypass

      
# root-bypass.js
Java.perform(function() {
    var RootBeer = Java.use('com.scottyab.rootbeer.RootBeer');
    RootBeer.isRooted.implementation = function() { return false; };
});

# ssl-bypass.js
Java.perform(function() {
    var TM = Java.use('javax.net.ssl.X509TrustManager');
    var SSL = Java.use('javax.net.ssl.SSLContext');
    var MyTM = Java.registerClass({
        name: 'com.bypass.TM', implements: [TM],
        methods: {
            checkClientTrusted: function(c,a) {},
            checkServerTrusted: function(c,a) {},
            getAcceptedIssuers: function() { return []; }
        }
    });
    var init = SSL.init.overload('[Ljavax.net.ssl.KeyManager;','[Ljavax.net.ssl.TrustManager;','java.security.SecureRandom');
    init.implementation = function(k,t,s) {
        init.call(this, k, [MyTM.$new()], s);
    };
});

# Run
frida -U -f com.target.app -l root-bypass.js -l ssl-bypass.js --no-pause

Automotive Security

    
Car Hacking Labs

    
CAN bus basics, ICSim virtual bench, OBD-II exploitation, key fob relay attacks, IVI hacking. Test only on vehicles you own or in dedicated bench environments.

    
Legal Warning: Automotive hacking can cause physical harm. Never test on public roads or vehicles you don't own.


    

      
 Lab Setup — Virtual CAN Bus

      
sudo apt install -y can-utils
pip3 install python-can cantools

git clone https://github.com/zombieCraig/ICSim
cd ICSim && make

# Create virtual CAN interface
sudo modprobe vcan
sudo ip link add dev vcan0 type vcan
sudo ip link set up vcan0

# Terminal 1: controls | Terminal 2: simulator | Terminal 3: sniff
./controls vcan0
./icsim vcan0
candump vcan0

    


    

      
 Lab 1: Sniff & Analyze CAN

      
candump vcan0
candump -l vcan0         # log to file
cansniffer vcan0         # diff view
cangen vcan0 -g 10 -I 244  # random traffic
cansend vcan0 244#0000000000

    


    

      
 Lab 2: Speedometer Manipulation

      
# Press accelerator in controls. Watch which ID changes (usually 0x244).
cansend vcan0 244#C800000000    # speed = 200 km/h
cansend vcan0 188#01000000      # left indicator
cansend vcan0 19B#000000000000  # doors

    


    

      
 Lab 3: Key Fob Relay Attack (Theory)

      
Keyless entry is vulnerable to relay attacks. Attacker A near car, Attacker B near victim's house, relaying challenge/response between them. Modern UWB keyfobs prevent this.

      
# Hardware for research/lab:
# Proxmark3, HackRF One, Yard Stick One
# Mitigation: faraday pouches, motion-sensor fobs, UWB

    


    

      
 Lab 4: OBD-II Exploitation

      
python3 -c "import obd; print(obd.OBD().query(obd.commands.PIDS_A))"
obd-speed     # read speed
obd-rpm       # read RPM
obd-dtc       # read DTCs

# UDS with udsoncan
python3 -c "
import udsoncan
from udsoncan.connections import PythonIsoTpConnection
from can.interfaces.socketcan import SocketcanBus
bus = SocketcanBus(channel='can0')
conn = PythonIsoTpConnection(udsoncan.connections.IsoTpConnection(bus))
client = udsoncan.Client(conn)
print(client.read_data_by_identifier(0xF190))
"

Aerospace Security

    
Aerospace Hacking Labs

    
ADS-B reception, GPS signal analysis, ACARS decoding, SATCOM basics. All labs are receive-only or shielded. Never transmit on aviation bands.

    
Critical: Transmitting on aviation frequencies is a federal crime. All labs below use receive-only SDR or shielded Faraday environments.


    

      
 Lab Setup

      
sudo apt install -y rtl-sdr gnuradio gnuradio-dev
git clone https://github.com/wiedehopf/readsb && cd readsb && make && sudo make install
sudo apt install -y acarsdec
pip3 install pyais gpsd-py3

      
Hardware: RTL-SDR (~$30), HackRF, Airspy, LimeSDR, Yagi/discone antenna at 1090 MHz.

    


    

      
 Lab 1: ADS-B Reception

      
sudo readsb --device-type rtlsdr --gain 40 --net
# Or:
dump1090 --net --interactive --gain 40
# Browser map:
firefox http://localhost:8080

      
# adsb.py — decode via TCP 30003
import socket
sock = socket.socket(); sock.connect(('localhost', 30003))
buf = ""
while True:
    buf += sock.recv(4096).decode('ascii', errors='ignore')
    while '\n' in buf:
        line, buf = buf.split('\n', 1)
        p = line.split(',')
        if len(p) > 15 and p[0] == 'MSG':
            print(f"ICAO: {p[4]}  Alt: {p[11]}ft  Speed: {p[12]}kt")

    


    

      
 Lab 2: GPS Signal Analysis (Shielded)

 Lab 3: ACARS Decoding

      
# Europe: 131.525, 131.725, 131.825 MHz | US: 131.550, 130.025 MHz
acarsdec -r 0 -f 131.725 -g 40

      
# acars-monitor.py
import subprocess
proc = subprocess.Popen(['acarsdec','-r','0','-f','131.725','-g','40'],
                        stdout=subprocess.PIPE, stderr=subprocess.DEVNULL)
for raw in proc.stdout:
    line = raw.decode('ascii', errors='ignore').strip()
    if line: print("[+] " + line)
