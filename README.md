## 🔥 About

**Hacking Arsenal** is a complete open-source hacking resource hub — CTF writeups, tool guides, bug bounty methodology, and reverse engineering tutorials. Everything is **free, legal, and practical**.

Built for beginners breaking into cybersecurity without paying for courses, and for researchers who want a clean reference.

<div align="center">

### 🎯 What's Inside

| 📖 Writeups | 🛠️ Tool Arsenal | 🐛 Bug Bounty | 🔬 Reverse Eng |
|:-----------:|:----------------:|:-------------:|:--------------:|
| TryHackMe & HTB walkthroughs | 2000+ tools with install guides | Real methodologies | Radare2, Ghidra |
| Step-by-step exploitation | Kali, Parrot, Termux | $20K+ bounty stories | Binary patching |
| Privilege escalation | Categorized & searchable | CVSS & disclosure | Crackme solutions |
